Cette migration met à jour vos bases de données vers la version 12.3 de MariaDB.

Les changements sont mineurs. Pour les consulter, rendez-vous sur la ou les notes de mises à jour concernées par votre
version actuelle (visible dans la section *Bases de données > MySQL* de votre compte).

- [Mise à jour vers MariaDB 12.3](https://mariadb.com/docs/server/server-management/install-and-upgrade-mariadb/upgrading/mariadb-community-server-upgrade-paths/upgrading-from-mariadb-11-8-to-mariadb-12-3)
